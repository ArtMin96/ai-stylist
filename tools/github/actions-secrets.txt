# GitHub Actions secrets and variables of this repository, as data.
# Read by `just repo-setup secrets` (scripts/security/github-secrets.sh): the report compares the
# names GitHub has with the names below, --apply sends the values this file allows from
# secrets/dev.enc.yaml. Guide: tools/github/README.md.
#
# One entry per line, fields separated by spaces, `#` starts a comment:
#   secret    NAME  SOURCE  required|optional  [after=NAME] [unread]
#   variable  NAME  SOURCE  required|optional  [after=NAME] [unread]
#   automatic NAME          GitHub Actions provides it itself; nothing to set
#   never     NAME          must never exist on GitHub as a secret or a variable, and is never a SOURCE
#   never-from-dev KEY      the value secrets/dev.enc.yaml holds for KEY is never sent to GitHub
# SOURCE is one of:
#   dev:KEY   the value of KEY in secrets/dev.enc.yaml (KEY is a shareable key of .env.example)
#   manual    a value this command never sends: the owner sets it by hand (the comment says how)
# required: a missing name is drift (exit 1). optional: a missing name is drift only when
#   secrets/dev.enc.yaml holds a value for its dev:KEY.
# after=NAME: sent only once NAME exists on GitHub (two values that are useless apart).
# unread: no workflow reads the name yet; without this flag an entry no workflow reads is an error.
# The offline check (run before every report and in `just test tooling`) fails when a workflow
# reads a secrets.NAME or vars.NAME that has no entry here, so this file cannot fall behind
# .github/workflows/**.
